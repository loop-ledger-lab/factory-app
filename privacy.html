factory 개인정보처리방침

시행일 2026년 10월 25일

누가 쓰나

factory는 채널 주인 한 사람이 자기 유튜브 채널에만 쓰는 개인 도구입니다. 다른 사람의 구글 계정에는 접근하지 않습니다.

구글에서 받는 권한과 쓰는 곳

  • youtube.upload: 채널 주인이 만든 영상을 그 채널에 올립니다.
  • youtube.force-ssl: 올린 영상에 자막을 붙이고 공개 상태와 공개 시각을 바꿉니다.
  • yt-analytics.readonly: 채널 주인의 영상 숫자(조회, 시청 시간, 노출, 클릭률)를 읽어 다음 영상을 고치는 데 씁니다.

보관과 공유

  • 구글이 준 접근 열쇠는 암호화된 비밀 저장소에만 두고, 화면이나 기록에 남기지 않습니다.
  • 받은 숫자는 채널 주인의 작업 기록에만 남기며, 팔거나 남에게 넘기지 않고 광고에 쓰지 않습니다.
  • 구글 API에서 받은 정보의 사용은 Google API Services User Data Policy의 제한적 사용(Limited Use) 요구 사항을 따릅니다.

권한 끊기

구글 계정의 서드 파티 앱 및 서비스 화면에서 factory를 지우면 바로 끊깁니다.

English summary: factory is a personal tool used only by the channel owner for their own YouTube channel. It requests youtube.upload (upload videos), youtube.force-ssl (captions and privacy status) and yt-analytics.readonly (read the owner's channel analytics). Tokens are kept only in an encrypted secret store. Data is never sold, shared or used for ads. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Revoke access at myaccount.google.com/permissions.
